# Описание проекта

Это приложение на языке программирования C++:

  - Проект представляет из себя графическое приложение для пользовательской среды.
  - Сборочный файл (для 'cmake') расположен в корневой папке проекта.
  - Исходный код приложения расположен в директории `src`, относительно корневой папки проекта.
  - Внешние библиотеки, которые используются в проекте - в директории `3rdparty`, относительно корневой папки проекта.


## Стандарты кодирования

  - Использовать язык C++ для всех новых файлов.
  - Следовать общему стилю проекта при именовании объектов, методов и классов.
  - Разработка ведется в среде "MS Visual Studio Code".
